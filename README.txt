# Football Player Management & Statistics System

## About the Project

This project is a relational database system built with Microsoft SQL Server to manage football player information, match results, and individual player statistics.

## Objectives

* Store football player profiles.
* Record football matches and results.
* Track goals, assists, minutes played, and disciplinary cards.
* Analyze player performances using SQL queries.
* Identify top scorers and players with the highest market values.

## Technologies

* Microsoft SQL Server
* T-SQL
* SQL Server Management Studio (SSMS)

## Database Tables

* **Players:** Stores player profiles and contract-related information.
* **Matches:** Stores match dates, teams, scores, and competitions.
* **PlayerStatistics:** Stores individual player performances in each match.

## SQL Skills Demonstrated

* CREATE TABLE
* INSERT, UPDATE, and DELETE
* SELECT and WHERE
* JOIN operations
* Aggregate functions
* GROUP BY and ORDER BY
* Primary and foreign keys
