# Football Player Management & Statistics System

## About the Project

ProjectFootball is a football player management and performance tracking database built using Microsoft SQL Server.
The project is designed to organize player information,record match performances, and analyze player statistics.

The database allows users to examine player performance through goals, assists, minutes played, and other match statistics.

## Objectives

* Store football player profiles.
* Record football matches and results.
* Track goals, assists, minutes played, and disciplinary cards.
* Analyze player performances using SQL queries.
* Identify top scorers and players with the highest market values.

## Technologies

* Microsoft SQL Server
* T-SQL
* SQL Server Management Studio (SSMS)

**Features**

**Player Management:** Store player information, including names, nationality, position, salary, and market value.
**Match Management:** Maintain records of football matches.
**Player Statistics:** Track goals, assists, minutes played, yellow cards, and red cards.
Top Scorers: Identify players with the highest goal totals.
Top Assist Providers: Identify players with the most assists.
Player Match History: Review individual performances across matches.
Player Rankings: Compare players based on their goal contributions.
Efficiency Rankings: Evaluate goals and assists relative to playing time.
Position Analysis: Compare player contributions across different positions
Database Structure

**The project includes three main tables:**

**Table	Description**
Players	Stores player information.
Matches	Stores match information.
PlayerStatistics	Records each player's performance in a match.

The tables are connected using primary and foreign keys to maintain relationships between players, matches, and statistics.
